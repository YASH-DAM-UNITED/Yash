# Yashwanth.L Premium Portfolio

Premium burgundy + black React/Vite portfolio.

## Local setup
1. Install Node.js 20+.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown by Vite.

## GitHub
Create a repository, then from this folder:
`git init`
`git add .`
`git commit -m "Initial portfolio"`
`git branch -M main`
`git remote add origin YOUR_REPOSITORY_URL`
`git push -u origin main`

## Cloudflare Pages
Import the GitHub repository into Cloudflare Pages.
Framework preset: Vite
Build command: npm run build
Build output directory: dist

No Wrangler file is required for a normal static Cloudflare Pages deployment.
